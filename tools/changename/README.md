# Smart Renamer - 智能文件批量重命名工具

## 项目介绍

Smart Renamer 是一款使用 Go + Fyne 开发的智能文件批量重命名工具，完全使用 Go 实现，无需额外依赖，易于构建和分发。

## 功能特性

1. **5种重命名规则**：
   - 序号填充：自定义起始数字、位数、前缀后缀
   - 查找替换：支持普通字符串和正则表达式
   - 日期标记：从文件修改时间提取日期作为前缀或后缀
   - 大小写转换：全大写/全小写/首字母大写/驼峰式
   - 扩展名修改：批量更改扩展名（含大小写统一）

2. 实时预览：显示原文件名→新文件名对照表
3. 支持多规则组合应用（按顺序执行）
4. 一键撤销：内置撤销功能
5. 冲突处理：遇到同名文件时自动编号避免冲突
6. 支持文件夹选择：通过图形界面选择文件夹

## 技术栈

- **后端**：Go 1.21+
- **GUI框架**：Fyne v2

## 开发环境准备

### 1. 安装 Go

下载并安装 Go 1.21 或更高版本：https://go.dev/dl/

## 构建方式

### Windows

方法一：使用批处理脚本（推荐）
```bash
build.bat
```

方法二：手动构建
```bash
go mod tidy
go build -ldflags "-s -w" -o build/smart-renamer.exe
```

构建完成后，可执行文件位于 `build\smart-renamer.exe`

### Linux/Mac

```bash
go mod tidy
go build -ldflags "-s -w" -o build/smart-renamer
```

## 使用说明

1. 启动应用
2. 点击「选择文件夹」按钮选择要重命名的文件所在文件夹
3. 在左侧勾选需要使用的重命名规则
4. 配置相应规则的参数
5. 在右侧查看重命名预览
6. 确认无误后点击「开始重命名」
7. 如需撤销，点击「撤销」按钮

## 核心功能说明

- 所有核心逻辑均在 `main.go` 中，模块化设计便于维护
- 使用并发（goroutine）扫描文件，提高效率
- 内置冲突解决机制，避免文件覆盖
- 完整的撤销功能，确保操作安全
