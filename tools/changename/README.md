# Smart Renamer - 智能文件批量重命名工具

## 项目介绍

Smart Renamer 是一款使用 Go 开发的智能文件批量重命名工具，采用纯命令行界面，无任何外部依赖，稳定可靠。

## 功能特性

1. **5种重命名规则**：
   - 序号填充：自定义起始数字、位数、前缀后缀
   - 查找替换：支持普通字符串和正则表达式
   - 日期标记：从文件修改时间提取日期作为前缀或后缀
   - 大小写转换：全大写/全小写/首字母大写/驼峰式
   - 扩展名修改：批量更改扩展名（含大小写统一）

2. 实时预览：显示原文件名→新文件名对照表
3. 支持多规则组合应用（按顺序执行）
4. 一键撤销：内置撤销功能
5. 冲突处理：遇到同名文件时自动编号避免冲突
6. 并发扫描：使用 goroutine 提高文件扫描效率

## 编译和运行

### 前置要求

需要安装 Go 1.21 或更高版本：https://go.dev/dl/

### Windows

#### 方法一：使用构建脚本（推荐）

直接双击运行 `build.bat` 即可。

#### 方法二：手动构建

```bash
# 1. 下载依赖
go mod tidy

# 2. 编译程序
go build -ldflags "-s -w" -o build\smart-renamer.exe
```

### Linux/Mac

```bash
go mod tidy
go build -ldflags "-s -w" -o build/smart-renamer
```

### 运行程序

编译成功后，在命令行中运行：

```bash
cd build
smart-renamer.exe
```

## 使用说明

程序启动后，按菜单提示操作：

1. **选择文件夹**：输入要重命名文件所在的文件夹路径
2. **配置重命名规则**：选择并配置需要使用的重命名规则
3. **预览重命名结果**：查看规则应用后的文件名变化
4. **执行重命名**：确认无误后执行重命名操作
5. **撤销上次操作**：如有需要，可撤销刚完成的重命名操作
6. **退出**：退出程序

## 使用示例

### 示例 1：序号填充

假设文件夹下有文件：
```
photo1.jpg
photo2.jpg
photo3.jpg
```

操作步骤：
1. 选择文件夹
2. 配置规则 1（序号填充）：
   - 启用规则
   - 起始数字：1
   - 位数：3
   - 前缀：IMG_
3. 预览结果：
   ```
   photo1.jpg  →  IMG_001.jpg
   photo2.jpg  →  IMG_002.jpg
   photo3.jpg  →  IMG_003.jpg
   ```
4. 执行重命名

### 示例 2：多规则组合

可以同时启用多个规则，按顺序应用。

例如：序号填充 + 日期标记

## 核心功能说明

所有核心功能均在 `main.go` 中实现：

- 文件扫描（并发处理）
- 重命名规则引擎（5种规则）
- 预览功能
- 重命名执行
- 撤销功能
- 冲突自动处理
